A live demo dies on stage, and the presenter reaches for the oldest excuse
in the book — the Wi-Fi. The Wi-Fi, of course, is innocent. The presenter
is not.

> My demo failed live, so I blamed the Wi-Fi. The Wi-Fi was fine. I was not.

`main.ts` (Node 22, stdlib only, no network) writes the joke to
`/output/entry.txt` — 74 characters, inside the gate's 1–280 range.
Deterministic: the same joke, byte for byte, on every run. v2 is a fresh
joke, written from scratch — it shares nothing with the v1 entry except
the competition.
